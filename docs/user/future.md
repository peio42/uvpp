# Future Features

Future work is tracked in the [proposal catalogue](../proposals/index.md).
The v3 architecture direction is accepted, while its specialized proposals remain
drafts. Acceptance is not a release commitment or documentation of a complete API;
some independent changes may also be suitable for v2.

The first v3 coroutine plumbing slice is available as an explicitly experimental
[coroutine guide](coroutines.md). It is not part of the stable v2 surface.

For the implemented library, use the [user documentation](index.md).
